# راهنمای بازی قیام کاوه

## هدف
در نقش کاوه آهنگر، از شش فصل عبور کن، نگهبانان ضحاک را شکست بده و در پایان درفش کاویانی را برافراشته کن.

## کنترل‌ها
- **چپ / راست:** حرکت کاوه در میدان نبرد
- **جاخالی:** جابه‌جایی سریع و ۶۵۰ میلی‌ثانیه مصونیت؛ زمان انتظار ۱٫۸ ثانیه
- **حمله:** یک واحد آسیب؛ فقط در فاصله نزدیک و با فاصله زمانی ۰٫۶ ثانیه
- **ضربه سنگین:** سه واحد آسیب؛ برد بیشتر و زمان انتظار ۸ ثانیه
- **معجون:** بازیابی یک واحد سلامتی؛ یک بار در هر تلاش
- **توقف:** لمس دکمه Ⅱ یا دکمه بازگشت دستگاه؛ لمس صفحه برای ادامه

## قوانین نبرد
- کاوه با سه واحد سلامتی وارد هر فصل می‌شود.
- دشمن در نوبت‌های زمان‌بندی‌شده حرکت می‌کند و در فاصله نزدیک حمله می‌کند.
- پیش از ضربه دشمن هشدار دیداری نمایش داده می‌شود؛ از جاخالی برای خنثی‌کردن ضربه استفاده کن.
- از فصل سوم، هر سومین نوبت دشمن یک حمله ویژه دوواحدی است.
- دشمن هر فصل از فصل قبل مقاوم‌تر است؛ ضربه سنگین را برای فرصت مناسب نگه دار.
- با شکست دشمن امتیاز می‌گیری؛ رکورد و پیشرفت روی دستگاه ذخیره می‌شود.
- خروج از برنامه در میانه نبرد، بازی را متوقف می‌کند تا هنگام بازگشت غافلگیر نشوی.

## فصل‌ها
1. **آتش آهنگری** — نگهبان ضحاک؛ نخستین ایستادگی کاوه
2. **فریاد ستم‌دیدگان** — سرباز ضحاک؛ پیوستن مردم
3. **گذرگاه کوهستان** — دیو کوهستان؛ عبور از گذرگاه افسانه‌ای
4. **سیاه‌چال ضحاک** — پاسدار سیاه‌چال؛ آزادی زندانیان
5. **خیزش مردم** — فرمانده ضحاک؛ حرکت به سوی کاخ
6. **درفش کاویانی** — ضحاک؛ نبرد پایانی و برافراشتن درفش

## ساخت و دریافت APK
گردش‌کار GitHub Actions با هر Push به `main`، هر Pull Request و اجرای دستی، آزمون‌های Kotlin را اجرا و نسخه Debug را می‌سازد. پس از موفقیت، فایل `KAVEH-RISING-debug-apk` را از بخش Artifacts همان اجرای workflow دریافت کن.
