# قیام کاوه — پروژه Unity

موتور: Unity 2022.3.62f1 — Android افقی.

## محتوای پیاده‌سازی‌شده
- دو مدل سه‌بعدی rigged از KayKit Adventurers: Barbarian برای کاوه و Mage برای ضحاک؛ هر دو روی Rig_Medium.
- پنج مجموعه انیمیشن CC0: حرکت پایه، حرکت پیشرفته، انیمیشن‌های عمومی، مبارزه نزدیک و ویژه؛ از طریق Unity glTFast وارد می‌شوند.
- ساخت خودکار Prefabهای کاوه و ضحاک، متریال‌های مجزا، چکش کاوه و تاج شاخ‌دار ضحاک هنگام اجرای BuildAndroid.
- کنترل حرکت در چهار جهت، مخفی‌کاری، تعامل با اهداف، جاخالی، حمله سبک و سنگین، سلامتی و معجون.
- ده فصل با هدف‌های مرحله‌ای و قابل تعامل، دشمنان، محیط‌های موضوعی، ذخیره پیشرفت و دوربین دنبال‌کننده.
- افکت‌های ذره‌ای و صداهای افکت/محیط تولیدشده در بازی.

## ساخت
در Unity، پروژه `UnityProject/` را باز کن و از منوی `Kaveh Rising > Build Android APK` استفاده کن. ساخت ابری GitHub Actions به secrets معتبر `UNITY_LICENSE`، `UNITY_EMAIL` و `UNITY_PASSWORD` نیاز دارد.

## خارج از محدوده فعلی
طبق درخواست کاربر، موسیقی متن و صداپیشگی فارسی اضافه نشده‌اند. زیرنویس فارسی و اتصال AudioClip برای مرحله بعد آماده است.

## وضعیت واقعی
مدل‌ها و کلیپ‌های انیمیشن واقعی به پروژه افزوده شده‌اند و اسکریپت ساخت Prefab آن‌ها را به بازی وصل می‌کند. محیط‌ها و برخی افکت‌ها هنوز procedural/low-poly هستند و همه فصل‌ها هنوز به یکسانی کیفیت هنری نهایی نرسیده‌اند. Unity Editor در این محیط اجرا نشده، بنابراین هنوز build موفق APK یا تست روی گوشی تأیید نشده است. قبل از اعلام نسخه نهایی باید import انیمیشن‌ها، prefabها، کنترل‌ها، نرخ فریم و APK روی دستگاه واقعی بررسی شوند.
