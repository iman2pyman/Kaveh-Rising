# قیام کاوه — پروژه Unity

این پوشه پروژه اصلی Unity بازی است. موتور هدف Unity 2022.3 LTS و پلتفرم Android است.

## باز کردن پروژه
در Unity Hub نسخه 2022.3.62f1 را نصب و پوشه `UnityProject` را باز کنید. سپس از منوی `Kaveh Rising > Build Android APK` صحنه آغازین را ایجاد و APK را بسازید.

## کنترل‌ها
حرکت چپ و راست، جاخالی، حمله عادی، ضربه سنگین، معجون و مکث از رابط لمسی روی صفحه انجام می‌شوند.

## وضعیت توسعه
این اولین انتقال واقعی هسته بازی به Unity است: ساختار ده فصل، کنترل شخصیت، تعقیب و حمله دشمن، مبارزه، سلامت، ذخیره پیشرفت و رابط لمسی در کد Unity قرار گرفته‌اند. مدل‌ها و محیط‌های فعلی هندسه موقت سه‌بعدی هستند؛ برای نسخه نهایی باید با مدل‌های هنری اختصاصی، ریگ و انیمیشن، صدا و بافت‌های باکیفیت جایگزین شوند. این پوشه هنوز نباید به‌عنوان نسخه نهایی آماده انتشار معرفی شود.

## ساخت خودکار
Workflow مربوط به Unity به لایسنس Unity Personal/Pro در GitHub Actions نیاز دارد. متغیرهای `UNITY_LICENSE`، `UNITY_EMAIL` و `UNITY_PASSWORD` باید به‌صورت repository secrets تنظیم شوند. تا پیش از تنظیم آن‌ها، ساخت ابری APK اجرا نمی‌شود.
