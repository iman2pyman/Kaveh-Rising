# قیام کاوه | KAVEH RISING

**موتور اصلی:** Unity 2022.3.62f1 — Android افقی  
**پروژه اصلی:** پوشه `UnityProject/`

## محتوای پروژه
پروژه Unity شامل بازی سه‌بعدی اندروید، مدل‌های rigged شخصیت‌های کاوه و ضحاک، مجموعه‌های انیمیشن، ده فصل داستانی، موج‌های مرحله‌ای دشمنان، کنترل لمسی، رابط و متن داستان فارسی، مأموریت‌ها، مخفی‌کاری و افکت‌های صوتی CC0 است. موسیقی متن و صداپیشگی فارسی طبق توافق فعلاً خارج از محدوده هستند.

## ساخت APK در Unity
۱. پوشه `UnityProject/` را با Unity نسخه **2022.3.62f1** باز کن و Android Build Support شامل SDK/NDK و OpenJDK را نصب داشته باش.  
۲. از منوی Unity گزینه `Kaveh Rising > Build Android APK` را اجرا کن.  
۳. فایل خروجی در مسیر `UnityProject/Build/KavehRising.apk` ساخته می‌شود.

## ساخت ابری از طریق GitHub
در مخزن GitHub وارد بخش **Actions** شو، گردش‌کار **Unity Android APK** را انتخاب کن و **Run workflow** را بزن. پس از ساخت موفق، فایل APK به‌صورت Artifact با نام `KAVEH-RISING-Android-APK` برای ۱۴ روز در دسترس خواهد بود.

برای ساخت ابری باید فایل XML لایسنس معتبر Unity را در تنظیمات مخزن، بخش **Settings > Secrets and variables > Actions** با نام `UNITY_LICENSE` ذخیره کنی. در صورت نیاز روش فعال‌سازی لایسنس، مقادیر `UNITY_EMAIL` و `UNITY_PASSWORD` را نیز به‌صورت Secret اضافه کن. هیچ‌وقت اطلاعات ورود یا فایل لایسنس را داخل سورس قرار نده.

## کنترل کیفیت
ابزار `Kaveh Rising > Validate Project Before Device Build` وجود فایل‌های ضروری، Prefabهای تولیدشده، تعداد انیمیشن‌ها، صحنه‌های فعال و پشتیبانی Android را بررسی می‌کند.

## وضعیت تأیید
هنوز ساخت موفق APK با Unity و آزمایش نصب و اجرای بازی روی گوشی واقعی از این محیط تأیید نشده است. تا زمانی که GitHub Actions با موفقیت اجرا نشود و بازی روی دستگاه اندرویدی آزمایش نشود، پروژه نسخه نهاییِ آزمایش‌شده محسوب نمی‌شود.
