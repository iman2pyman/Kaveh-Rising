# قیام کاوه | KAVEH RISING

**موتور اصلی:** Unity 2022.3.62f1 — Android افقی

پوشه `UnityProject/` منبع اصلی بازی سه‌بعدی است. پروژه شامل ده فصل داستانی، ۱۷ موج دشمن، مبارزه سوم‌شخص سه‌بعدی، مخفی‌کاری، اکتشاف، اهداف تعاملی، کنترل لمسی و ذخیره پیشرفت است.

## محتوای واقعی مخزن
- مدل‌های rigged و تکسچر KayKit برای کاوه و ضحاک، همراه با Prefab builder.
- پنج مجموعه انیمیشن KayKit Rig_Medium شامل حرکت پایه/پیشرفته، عمومی، مبارزه نزدیک و حرکات ویژه؛ کلیپ‌ها در Unity به AnimationClipهای قابل پخش تبدیل می‌شوند.
- کنترل حرکت چهارجهته، دویدن، مخفی‌کاری، جاخالی، حمله سبک و سنگین، تعامل، معجون سلامتی، مکث و HUD فارسی.
- مأموریت‌های متمایز شامل آتشدان، نجات زندانیان، همراه کردن مردم، درفش کاویانی، زنجیرها، بت‌های مار و آتش راهنمای البرز.
- افکت‌های ذره‌ای و فایل‌های صوتی واقعی CC0 برای ضربه، سلاح، چکش، فلز، در و قدم‌ها.
- ده فصل و موج‌های دشمن مرحله‌ای؛ نبرد نهایی ضحاک سه موج دارد.

## موارد خارج از محدوده فعلی
طبق درخواست کاربر، **موسیقی متن و صداپیشگی فارسی اضافه نشده‌اند**. زیرنویس داستانی فارسی و اتصال فایل صوتی برای مرحله بعد آماده است.

## ساخت APK
در Unity 2022.3.62f1 پوشه `UnityProject/` را باز کن و از منوی `Kaveh Rising > Build Android APK` استفاده کن. این فرمان Prefabها و AnimationClipها را از دارایی‌های موجود می‌سازد و سپس APK اندروید را تولید می‌کند. ساخت ابری GitHub Actions نیازمند secrets معتبر `UNITY_LICENSE`، `UNITY_EMAIL` و `UNITY_PASSWORD` است.

## وضعیت تأیید
دارایی‌های سه‌بعدی، انیمیشن‌ها و SFX در مخزن موجودند و سیستم ساخت Prefab به آن‌ها متصل شده است. با این حال، Unity Editor در این محیط اجرا نشده؛ بنابراین هنوز build موفق APK و تست روی گوشی واقعی تأیید نشده است. تا انجام این دو کار، این پروژه را نسخه نهاییِ آزمایش‌شده معرفی نمی‌کنیم.
