# قیام کاوه — پروژه Unity

موتور اصلی Unity 2022.3.62f1 و خروجی هدف Android افقی است.

## محتوای مرحله سوم
- شخصیت‌پردازی سه‌بعدی low-poly با اجزای بدن، لباس، پیش‌بند آهنگری، ریش، زره و شاخ‌های دشمن؛ بدون فایل حجیم و وابستگی خارجی.
- ده فضای فصل با نشانه‌های محیطی متفاوت مانند آهنگری، کوهستان، سیاه‌چال و بت‌های مار.
- دوربین دنبال‌کننده، مبارزه، جاخالی، دشمن تعقیب‌کننده و پیشرفت ذخیره‌شونده.
- افکت ذرات برای برخورد و شکست دشمن.
- صدای محیط آهنگری و افکت‌های ضربه، آسیب و پیروزی به‌صورت موج صوتی تولیدشده در زمان اجرا. این‌ها placeholder صوتی‌اند و ضبط موسیقی/گویندگی حرفه‌ای نیستند.
- کنترل لمسی، رابط فارسی و ده فصل روایی.

## ساخت APK
از منوی Unity: `Kaveh Rising > Build Android APK`. Workflow ابری به secrets معتبر `UNITY_LICENSE`، `UNITY_EMAIL` و `UNITY_PASSWORD` نیاز دارد.

## وضعیت و محدودیت صادقانه
این نسخه از نمونه اولیه ساده فراتر رفته و محتوای سه‌بعدی و افکت‌های procedural دارد، اما هنوز دارایی هنری دست‌ساز/واقع‌گرایانه، موشن‌کپچر، موسیقی و صداپیشگی ضبط‌شده ندارد. مهم‌تر اینکه در این محیط Unity Editor اجرا نشده و APK روی دستگاه واقعی تست نشده؛ بنابراین تحویل آن به‌عنوان نسخه نهایی تأییدشده درست نیست. قبل از انتشار باید build واقعی، تست کنترل لمسی، صدا، نرخ فریم و سازگاری Android انجام شود.


## مدل سه‌بعدی و انیمیشن
- مدل Humanoid واقعی Quaternius در `Assets/Resources/Characters/KavehHumanoid.glb` قرار دارد و با glTFast 6.14.1 وارد Unity می‌شود.
- مجوز مدل CC0 1.0 در `Assets/Resources/Characters/Quaternius-CC0-LICENSE.txt` ثبت شده است.
- در صورت موفقیت Import، بازی از مدل rigged واقعی استفاده می‌کند؛ اگر Import در Unity انجام نشود، fallback procedural باقی می‌ماند.
- `RiggedCharacterAnimation` انیمیشن‌های keyframed حرکت، دویدن، خم‌شدن، حمله، ضربه سنگین، جاخالی، آسیب و مرگ را روی استخوان‌های مدل ایجاد می‌کند. این‌ها انیمیشن‌های رویه‌ای هستند، نه موشن‌کپچر.
- موسیقی متن و صداپیشگی فارسی عمداً خارج از محدوده این نسخه‌اند.
