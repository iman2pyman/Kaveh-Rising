# KAVEH RISING | قیام کاوه

**موتور فعال:** Godot 4.7.2 — Android  
**پروژه اصلی:** `GodotProject/`  
**آرشیو منابع Unity:** `UnityProject/` (بدون حذف و محفوظ)

## وضعیت فعلی
پروژه Godot اکنون شامل کمپین ده‌فصلی و ۱۷ موج نبرد، مدل‌های سه‌بعدی rigged کاوه و دشمنان، پنج کتابخانه انیمیشن، موجودات افسانه‌ای، باس ضحاک با دو سر مار، اهداف آزادسازی زندانیان، درفش کاویانی، مبارزه و جاخالی، رابط فارسی و کنترل لمسی است. افکت‌های صوتی رزمی و محیطی نیز وارد شده‌اند؛ موسیقی متن و صداپیشگی فارسی عمداً برای مرحله بعد نگه داشته شده‌اند.

## دریافت نسخه آزمایشی اندروید
1. وارد بخش **Actions** مخزن شوید.
2. اجرای موفق **Godot Android APK** را باز کنید.
3. artifact با نام `KAVEH-RISING-Android-debug` را دانلود کنید.

Workflow پروژه را وارد و اعتبارسنجی می‌کند، دارایی‌های rig و انیمیشن را بررسی می‌کند، تست خودکار شروع کمپین/نجات زندانی/باس نهایی/توقف و ادامه را اجرا می‌کند و سپس APK آزمایشی را می‌سازد. artifactها ۱۴ روز نگهداری می‌شوند.

## کنترل‌ها
- موبایل: جهت‌ها، «ضربه»، «جاخالی»، «آزادسازی» و دکمه توقف.
- دسکتاپ: WASD یا جهت‌ها، Space برای حمله، Shift برای جاخالی و E برای تعامل.

## موارد باقی‌مانده تا انتشار
ساخت APK در CI و تست خودکار موفق شده است؛ با این حال نصب و آزمایش نهایی روی چند گوشی واقعی، تنظیم دقیق تعادل دشواری و جایگذاری موسیقی و صداپیشگی فارسی هنوز لازم است. خروجی فعلی debug است و نسخه فروشگاهی باید جداگانه با کلید انتشار امضا شود.

برای جزئیات فنی و مجوز دارایی‌ها به `GodotProject/README.md` و `GodotProject/ASSET_CREDITS_FA.md` مراجعه کنید.
