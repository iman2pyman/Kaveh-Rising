# KAVEH RISING | قیام کاوه

**موتور اصلی: Unity 2022.3.62f1 — Android**

پوشه `UnityProject/` پروژه اصلی سه‌بعدی است. کد Native Android قدیمی فقط میراث نمونه اولیه است.

## مسیر پروژه
- پروژه Unity: `UnityProject/`
- راهنمای فارسی: [UnityProject/README_FA.md](UnityProject/README_FA.md)
- ساخت APK: منوی Unity `Kaveh Rising > Build Android APK`
- ساخت ابری: GitHub Actions (نیازمند secrets معتبر Unity)

## وضعیت توسعه
دو شخصیت rigged از KayKit، پنج مجموعه انیمیشن CC0 از KayKit، ده فصل با هدف‌های مرحله‌ای، مبارزه، مخفی‌کاری، تعامل، کنترل چهارجهته و محیط‌های موضوعی در پروژه قرار گرفته‌اند. موسیقی متن و صداپیشگی فارسی بنا به درخواست کاربر خارج از محدوده فعلی هستند.

هنوز APK ساخته و روی گوشی واقعی آزمایش نشده؛ بنابراین این مخزن را نسخه نهایی تأییدشده معرفی نمی‌کنیم. جزئیات دارایی‌ها، مجوزها و وضعیت در راهنمای Unity آمده است.
